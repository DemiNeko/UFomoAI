# Защита проекта «Научи ИИ»

## Выступление на 2–3 минуты

«Мой проект — веб-приложение для распознавания телефона, руки и тетради. Цель — показать полный цикл небольшого эксперимента с машинным обучением: сбор примеров, обучение классификатора и проверку на новых изображениях.

Сначала пользователь показывает предметы камере и собирает примеры с правильными метками. Это обучение с учителем. Для каждого класса желательно собрать хотя бы 20–40 кадров с разными ракурсами, фонами и освещением.

Готовая нейросеть MobileNet преобразует кадр в вектор из 512 признаков. Её веса уже обучены на большом наборе изображений, поэтому мы используем перенос признаков и не тренируем большую нейросеть с нуля.

Далее мой классификатор kNN сравнивает новый вектор с сохранёнными примерами. Для сравнения используется косинусное сходство. Пять ближайших примеров голосуют за класс. Если согласия или сходства недостаточно, программа показывает “Не уверен”.

Теперь я покажу работу на новых ракурсах. Проценты справа — это доля голосов соседей, а не измеренная точность. Чтобы оценить точность, нужно собрать отдельные тестовые примеры, которых не было в обучении.

Все вычисления выполняются в браузере. Приложение можно открыть по ссылке GitHub Pages; установка Python, сервер распознавания и платный API не нужны. Обученные примеры сохраняются в JSON и загружаются перед следующим показом».

## Подготовка перед показом

1. Проверь доступ к камере в том браузере, которым будешь пользоваться.
2. Подготовь телефон и тетрадь, выбери удобное освещение. Для класса «Рука» покажи ладонь без предмета.
3. Собери примерно одинаковое число разнообразных примеров каждого класса. Сохрани JSON.
4. Перед выступлением открой сайт, загрузи JSON, нажми «Обучить классификатор», включи камеру. Если освещение или устройство изменились, добавь новые примеры и обучи снова.
5. Покажи нормальный результат, затем сложный ракурс и объясни возможную ошибку. Не обещай безошибочную работу.
6. Если камера не работает, используй заранее подготовленные фотографии: отдельно обучающие и тестовые.

## Вопросы преподавателя

**Где здесь искусственный интеллект?**
Нейросеть извлекает признаки изображения. Классификатор обобщает размеченные примеры, чтобы дать ответ для нового кадра. Правила вида «если чёрный прямоугольник, значит телефон» не задаются вручную.

**Что именно обучается?**
Мы строим собственный классификатор на своих примерах. В kNN обучение означает сохранение нормализованных признаков с метками. Веса MobileNet не меняются; градиентного спуска и эпох в этой версии нет.

**Почему не обучали нейросеть с нуля?**
Для этого нужно намного больше разнообразных размеченных изображений и вычислений. Перенос признаков позволяет провести учебный эксперимент на небольшом наборе.

**Почему пять соседей?**
Это простое выбранное значение k, которое уменьшает влияние одного нетипичного примера. Оно не доказано оптимальным; его можно подобрать по отдельной валидационной выборке.

**Что такое косинусное сходство?**
Скалярное произведение двух векторов, делённое на произведение их длин. После нормализации до единичной длины достаточно скалярного произведения. Более высокое значение означает более похожие признаки.

**Как оценить качество?**
Подготовить отдельные тестовые данные. Например, по 10 новых показов каждого класса. Посчитать долю правильных ответов и составить таблицу ошибок. Результаты нужно реально измерить: в проекте нет выдуманного показателя точности.

**Почему модель ошибается?**
Примеров может быть мало, они могут быть слишком похожими. Модель может запомнить фон, освещение или руку вместо объекта. Есть только три класса, поэтому неизвестные предметы иногда ошибочно относятся к одному из них. Порог неопределённости уменьшает часть ошибок, но не устраняет их.

**Что хранится и куда отправляется камера?**
Камера не отправляется на сервер. В памяти браузера хранятся признаки и несколько миниатюр. Экспорт содержит признаки и метки классов. После закрытия страницы несохранённые примеры теряются.

**Что можно улучшить?**
Добавить отдельный класс фона, собрать более разнообразный набор, сравнить значения k, построить матрицу ошибок на независимых тестовых данных, сравнить kNN с обучаемым выходным слоем нейросети.
