# Научи ИИ — телефон, рука, тетрадь

Мини-проект по искусственному интеллекту: пользователь собирает примеры трёх классов, обучает классификатор и проверяет распознавание в браузере.

**[Открыть лабораторию →](https://demineko.github.io/UFomoAI/)** · [Текст для защиты](docs/DEFENSE.md)

**Настоящее машинное обучение:** готовая MobileNet v1 извлекает признаки изображения, а собственная реализация kNN классифицирует новые кадры по обучающим примерам. Ответы не зашиты в интерфейс. Веса нейросети не переобучаются.

## Быстрый запуск

Нужен Node.js 22 или новее. В папке проекта:

```sh
npm start
```

Открой **http://localhost:4173** в Chrome или Edge. Для запуска приложения `npm install` не нужен. Файлы TensorFlow.js и MobileNet уже находятся в `dist/`: при локальном запуске внешний интернет не нужен. Не открывай `index.html` двойным щелчком: ES-модули и камера требуют HTTP на localhost либо HTTPS.

Камера запрашивается только после нажатия «Включить камеру». Кадры и признаки не отправляются на сервер. На GitHub Pages браузер только скачивает приложение и веса модели; изображения обрабатываются на устройстве пользователя.

## Эксперимент

1. Включи камеру и разреши доступ. Если камеры нет, добавь фотографии кнопкой загрузки у каждого класса.
2. Покажи **телефон**, нажми **«+ 20 кадров»** в его карточке. Во время сбора медленно меняй ракурс и расстояние. Повтори для **руки** и **тетради**. Минимум — 5, рекомендуется 20–40 разнообразных примеров, максимум — 300 на класс.
3. Нажми **«Обучить классификатор»**. kNN сохраняет нормализованные признаки; здесь нет долгой оптимизации весов или искусственной анимации обучения.
4. Нажми **«Начать распознавание»** или **«Проверить на фотографии»**. Новые снимки не добавляются в обучение автоматически.
5. Сохрани набор кнопкой **«Сохранить набор»**. Перед защитой загрузи JSON и нажми «Обучить классификатор». Файл содержит признаки и метки, без исходных фотографий и видеозаписи. После перезагрузки несохранённые примеры исчезнут.

Обрабатывается центральный квадрат изображения, соответствующий области предпросмотра. Для класса «Рука» показывай свободную ладонь; телефон и тетрадь пусть занимают большую часть кадра. Иначе классификатор может запомнить руку, лицо или фон вместо предмета. Подготовь разные фоны и освещение для каждого класса, старайся держать количество примеров примерно одинаковым.

## Публикация на GitHub Pages

Готовый workflow находится в `.github/workflows/pages.yml`. Он публикует только папку `dist/`, проверяет синтаксис JavaScript и запускает тесты классификатора.

В репозитории `DemiNeko/UFomoAI` публикация уже настроена: изменения в ветке `main` обновляют сайт автоматически. Шаги ниже нужны, если ты размещаешь свою копию проекта в другом репозитории.

1. Создай пустой **публичный** репозиторий, например `teach-ai-lab`, без автоматического README.
2. В папке этого проекта выполни команды, заменив `YOUR_USERNAME` на свой GitHub-логин:

```sh
git init -b main
git add .
git commit -m "Add browser AI learning lab"
git remote add origin https://github.com/YOUR_USERNAME/teach-ai-lab.git
git push -u origin main
```

3. На GitHub открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В **Actions** открой **Publish AI Lab to GitHub Pages** и при необходимости запусти **Run workflow**. Дождись успешного выполнения. Адрес появится в **Settings → Pages**; обычный адрес — `https://YOUR_USERNAME.github.io/teach-ai-lab/`.

Пути к ресурсам относительные, поэтому сайт работает и в подпапке репозитория. GitHub Pages даёт HTTPS для камеры. При ошибке деплоя сначала проверь выбранный Source и разрешение Actions в репозитории. Проект не требует секретов, API-ключей и платного хостинга.

## Как устроено

```text
Камера / фотография
       ↓
Центральный квадрат → 224×224 RGB → нормализация [-1, 1]
       ↓
MobileNet v1 0.50 → conv_pw_13_relu → усреднение по координатам
       ↓
512 признаков → нормализация до единичной длины
       ↓
Косинусное сходство с обучающими примерами
       ↓
5 ближайших соседей → голосование → класс / «Не уверен»
```

Алгоритм находится в `dist/classifier.js`: нормализация, построение классификатора, поиск соседей, голосование и проверка JSON. `dist/app.js` связывает его с камерой и нейросетью.

**Шкалы показывают долю голосов среди 5 соседей, а не статистически откалиброванную вероятность или измеренную точность.** «Не уверен» выводится, если победитель получает менее 80% голосов или сходство с ближайшим примером ниже 0,65. Это эвристика для демонстрации, а не гарантия обнаружения неизвестных предметов. Модель обучается только трём классам и может уверенно ошибаться на фоне или других объектах.

Чтобы измерить точность, подготовь по 10 **новых** показов каждого класса, запиши ожидаемый и полученный ответы. Точность = правильные ответы / 30 × 100%. Для честного отчёта «Не уверен» считай ошибкой и отдельно укажи количество таких случаев. Последовательные кадры одной серии слишком похожи: не используй их одновременно как обучение и тест.

## Проверки

```sh
npm run check
npm test
```

Для браузерных проверок:

```sh
npm run test:browser
```

Открой http://localhost:4174/__tests__/browser.html в Chrome или Edge и нажми «Запустить проверки». Тесты используют синтетический видеопоток и проверяют работу приложения, а не точность на реальных предметах. Доступ к физической камере не запрашивается. Этот тестовый маршрут доступен только при запуске с `--test` и не публикуется на GitHub Pages.

Исходники зависимостей и веса можно повторно загрузить командой `npm run assets` (только для этого нужен интернет). Версия TensorFlow.js закреплена на 4.22.0. SHA-256 загруженных файлов записаны в `dist/asset-hashes.json`.

## Файлы

- `dist/` — готовый сайт, библиотека и веса модели.
- `scripts/serve.mjs` — локальный сервер без зависимостей.
- `scripts/download-assets.mjs` — воспроизводимая загрузка внешних файлов.
- `tests/` — проверки классификатора и пользовательских сценариев.
- `docs/DEFENSE.md` — текст выступления и ответы на вопросы преподавателя.
- `.github/workflows/pages.yml` — публикация сайта.

Технологии: HTML, CSS, JavaScript, TensorFlow.js, MobileNet, kNN. Атрибуция и лицензии зависимостей: [THIRD_PARTY_NOTICES](dist/THIRD_PARTY_NOTICES.txt).
